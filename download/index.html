Before you start

Three things you'll need.

An Android panel

Your car screen must run Android 6.0 or newer. Almost every aftermarket panel does.

A USB stick

Any size. This is how the file gets from your phone or computer to the panel.

The panel's File Manager

Every Android panel has one — sometimes called Files, Explorer, or ES File Explorer.

The USB method

Six steps, about five minutes.

This is how most people install DashLink. You don't need Wi-Fi in the car, and you don't need a Google account on the panel.

1

Download the file on your phone or computer

Tap the Download DashLink button at the top of this page. You'll get a single file ending in .apk.

Your browser may warn that this file type can harm your device. That warning appears for every APK. Choose Download anyway.

2

Copy the file to a USB stick

Plug the USB stick into your computer and drag the .apk file onto it. On a phone, use an OTG adapter and your Files app.

Put it in the main folder of the stick, not inside another folder — it's much easier to find on the panel.

3

Plug the stick into your car's panel

Use the USB port on your head unit. Start the car (or put it in accessory mode) so the screen is on.

If you have two USB ports and one doesn't work, try the other — some are wired for power or a reverse camera only.

4

Open the File Manager on the panel

Find the app called Files, File Manager or Explorer on your panel, open it, and go to the USB stick.

The stick usually appears as USB, udisk or sda1.

5

Tap the file and allow the install

Tap the .apk file. Android will ask whether to allow installing apps from this source — turn the switch on, go back, and tap Install.

This permission is per-app: you're allowing your File Manager to install, not turning off security for the whole panel.

6

Open DashLink and start your free trial

DashLink appears in your panel's app list. Open it, and your 7-day free trial starts — no payment, no card.

Connect the panel to Wi-Fi or a phone hotspot the first time so the trial can activate. After that it works offline.

No USB stick? Download straight onto the panel

If your panel has a working browser and you can connect it to Wi-Fi or your phone's hotspot, you can skip the USB entirely:

  1. Connect the panel to Wi-Fi or your phone's hotspot.
  2. Open the browser on the panel and type this address: dashlink-automotive.github.io/download
  3. Tap Download DashLink, then open the downloaded file from the notification.
  4. Allow the install, and you're done.

Many panel browsers are old and slow, which is why we recommend the USB method first. If the download stalls, use the USB stick instead.

If something goes wrong

Common snags, solved.

That's the most common mix-up, and it's an easy fix. DashLink is built for the Android screen in your car, not for phones — on a phone there's nothing for it to do. Uninstall it from your phone if you like, then follow the six steps above to install it on your panel instead.

Android needs permission before an app can install software. When the prompt appears, turn the switch on for the app you're installing from (usually your File Manager), then press back and tap Install again. On older panels you may find it under Settings → Security → Unknown sources instead. This grants permission to that one app, not to the whole system.

Try the other USB port — on many units one port is wired only for power or a reverse camera. Also try formatting the stick as FAT32, which older panels handle best, and use a smaller stick if you have one. Some panels only detect a stick that was plugged in before the unit powered on.

Look for an app called Files, Explorer, File Browser or ES File Explorer — it's sometimes tucked inside a folder of system tools. If there genuinely isn't one, message us on WhatsApp and we'll help you get one onto the panel first.

A parse error usually means the file didn't copy completely — download it again and re-copy it to the stick. "App not installed" often means an older or differently-signed copy of DashLink is already there; uninstall the existing one first, then install again.
